# Race Kit — piezas de personaje (WIP)

Kit modular de piezas (cabeza, torso, brazos L/R, manos, muslos, pantorrillas, pies bare/heels L/R) para razas fantasy, estilo realista tipo Mari.

> **Las imágenes en `_catalog/preview-*.png` son muestras de progreso**, no el kit completo.

## Estructura
```
{race}/{gender}/{variant}/{outfit}/{part}[-{side}].png
```
- Razas: elves, orcs, hobbits, humans-north, humans-south, lizardfolk, sheepfolk
- Variantes: `a`, `b` (dos de cada)
- Outfit: `clothed`, `underwear` (`nude` bloqueado por el generador)
- Pies: `foot-bare-L/R`, `foot-heels-L/R`
- Proporción catálogo: eje largo normalizado a **512 px**
